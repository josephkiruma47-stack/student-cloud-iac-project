Project Overview

This website demonstrates a simple cloud-hosted application deployed through an automated CI/CD pipeline. The project uses Infrastructure as Code to create Azure resources and GitHub Actions to deploy updates automatically.

Tools Used

Microsoft Azure

Used to host the web application through Azure App Service.

Terraform

Used to create cloud infrastructure using Infrastructure as Code.

GitHub Actions

Used to automate deployment whenever code is pushed to GitHub.

CI/CD Pipeline

  1. Developer updates the website code.
  2. Changes are committed to GitHub.
  3. GitHub Actions workflow runs automatically.
  4. The website is deployed to Azure App Service.
  5. The live website updates without manual deployment.
